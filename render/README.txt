FLOWGUARD INTERACTIVE ESTATE
Ready-to-host static website files, including the estate, Sentinel model and branding.

Extract this ZIP and upload the flowguard-website folder to your static web host.
index.html must sit at the root of the deployed folder. Keep assets and vendor folders intact.
No build command or backend is required.

Local preview: serve this folder with an HTTP server; opening index.html directly from disk will not reliably load the 3D assets.

Move: drag or scroll to travel. Orbit: drag to rotate and scroll to zoom.
Arrow keys / WASD move. Plus and minus zoom. Layers & assets offers street shortcuts.

All readings are simulated. A browser with WebGL 2 is required.
Browser interaction and responsive visual QA remain unverified in the restricted preview environment.
